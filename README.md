# Omniscope

AI data-exploration interface for analyst-facing insight workflows.

This repo is kept public as a UI and product-thinking artifact for AI implementation roles. The relevant signal is the interface pattern: help users move from scattered data and questions toward structured exploration, visual context, and decision support.

## What It Demonstrates

- React and TypeScript product implementation
- shadcn/ui and Tailwind-based interface composition
- Data workflow thinking for analysts and operators
- Fast iteration from concept to usable front-end surface

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Local Development

```sh
npm install
npm run dev
```

## Status

Portfolio-ready implementation artifact. The value is the AI/data workflow interface pattern and rapid product iteration.
