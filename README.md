# Omniscope

AI data-exploration prototype for analyst-facing insight workflows.

This repo began as a Lovable/Vite prototype. It is kept public as a UI and product-thinking artifact rather than as a production system. The relevant signal for AI implementation roles is the interface pattern: help users move from scattered data and questions toward structured exploration, visual context, and decision support.

## What It Demonstrates

- React and TypeScript product prototyping
- shadcn/ui and Tailwind-based interface composition
- Data workflow thinking for analysts and operators
- Fast iteration from concept to usable front-end surface

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Local Development

```sh
npm install
npm run dev
```

## Status

Prototype. Not positioned as production software. The value is the AI/data workflow interface pattern and rapid product iteration.
